# Accessibility First

Read repository-local policy first. If local policy conflicts with this skill, report `POLICY CONFLICT:`. If required accessibility behavior is missing, report `AMBIGUITY:`.

Accessibility-visible text is localization-covered text. Labels, hints, roles, values, announcements, keyboard command descriptions, errors, and recovery guidance must use the approved native localization mechanism.

Preserve native platform accessibility APIs and conventions. Do not postpone accessibility until after release.

When changing UI behavior, identify keyboard, assistive-technology, text-scaling, contrast, focus, reduced-motion, and localized text-expansion impacts where applicable.
